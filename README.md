One funny fortune-cookie line for an AI agent, in the voice of a fortune slip.

`main.ts` copies `entry.txt` byte-for-byte to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
It refuses an empty / whitespace-only entry or one over 140 characters (exit 1).
